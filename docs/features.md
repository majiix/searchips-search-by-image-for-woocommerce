# Project Features

## Search Strategies
- **Strategy 1 (Vector Embeddings)**: Multimodal visual similarity matching using vector embeddings (defaults to the standard Google multimodal embeddings model).
- **Strategy 2 (Vision-to-Text)**: Standard WooCommerce search using image descriptions generated by a vision model (defaults to the standard Google vision model).

## Admin Controls
- **API Settings**: Configurations for OpenRouter API Key, model selections, and a custom maximum upload size option (defaulting to 2MB). Features a premium Show/Hide password visibility toggle to prevent copy-paste header errors. All settings are strictly sanitized and validated using custom CSS layout, color, size, strategy, and number sanitizers.
- **Dynamic Model Selection**: Fetches and filters embedding and vision models in real-time directly from OpenRouter's public API to display as dropdown selections.
- **Images Selection for Indexing**: Checkbox settings to specify whether to index the Featured Image, Product Gallery Images, or both.
- **Copy Logs button**: One-click copying of indexer logs directly to the clipboard.
- **Batch Indexing**: Real-time tracking and indexing panel with AJAX-driven progress indicators. Automatically skips empty images and missing files on disk.
- **Indexer Controls**: Real-time Pause and Stop controls to suspend or cancel indexing safely between batches.
- **Exclusion Threshold Option**: Configurable percentage threshold ("Exclude Products Below Match Percentage") to omit products falling below match criteria.
- **Informational Help Sidebar**: A modern two-column layout providing contextual guides about match score dynamics and indexer features directly inside settings.
- **Test Search Tab**: Built-in visual sandbox enabling site admins to test search queries, upload images, watch neon laser scan animations, and inspect similarity matching outcomes directly in the admin dashboard. Securely authenticated using nonce verification and user capability checks to prevent unauthorized access.
- **Settings Saved Feedback**: Integrates standard WordPress error and success notification templates to display clean visual feedback to administrators when settings are successfully saved or when validation checks fail.


## Frontend Search UI
- **Camera Search Button**: Integrated camera trigger inside search forms.
- **Camera Styling Customizer**: Option fields inside a dedicated "Styling" settings tab to set custom left position, right position, size, and background color values (using a native WordPress color picker UI) for the frontend camera icon trigger, automatically generating clean inline CSS overrides.
- **Drag-and-Drop Uploader**: Direct upload overlay with preview.
- **Client-Side Image Cropping**: Integrates the latest stable version of Cropper.js (v2.1.1) utilizing modern Web Components for smooth client-side cropping before search submission, pre-configured to cover exactly 90% of the loaded image's boundaries.
- **Scanning Animation**: Visual scanner indicator during processing.
- **Default Search Page Integration**: Redirects visual search requests directly to your theme's default WooCommerce product search results page using a clean query token (`vquery`) and server-side transients, leveraging your active theme's native styling and archive grid layouts.


## Database Logging & Cron
- **System Logs Tab**: A dedicated admin panel tab showing detailed plugin logs (timestamp, message, context metadata) with Copy and Clear options.
- **Log Retention settings**: Ability to disable database logging or customize retention periods (e.g. 1 day, 7 days, 30 days) to keep database size optimal.
- **Background Cron Indexing**: Hourly background cron scheduler option to process product image indices asynchronously without keeping settings open.
- **Auto-Reindexing Hooks**: Listeners for product updates and gallery/featured image postmeta additions or updates to instantly trigger automatic re-indexing of product visual data.
- **Strategy Change Auto-Cron**: Automatically schedules a background cron job to clear all existing index data and cache transients when the search strategy option is changed, ensuring search compatibility.
